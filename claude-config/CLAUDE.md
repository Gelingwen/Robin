# 全局工作约定

## 语言
- 默认用中文回复；代码、命令、文件名保持原样。

## 开始任务前
- 先看 `~/.claude/feedback.md` 里"状态：未处理"的条目，涉及当前任务的要遵守。

## 用户纠错时
- 用户指出错误、或重复提同一条意见时，先按 `self-improve` skill 的格式把反馈记到 `~/.claude/feedback.md`，再修正当前工作。
- 同一问题第二次出现，或未处理条目达到 3 条，提议用 `self-improve` skill 改造对应的 Skill；用户同意后再动手。

## 改文件的底线
- 不覆盖用户没确认的重要原始文件；先写新文件或开分支。
- 说"验证通过"必须附证据（命令输出、对比结果）；没跑过就写"尚未验证"。
